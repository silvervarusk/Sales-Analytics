# 📊 Nädal 4 – SQL Agregatsioon

## 🎯 Eesmärk

Kasutasime SQL agregatsioonifunktsioone, CTE-sid ja Window Functioneid UrbanStyle andmebaasis, et analüüsida müüki, kliente, inventuuri ja turunduskanalite tulemuslikkust ning koostada juhtkonnale andmepõhiseid soovitusi.

## 💡 Äriline fookus

Analüüside eesmärk oli toetada UrbanStyle juhtkonda:

- müügitrendide mõistmisel
- väärtuslike klientide tuvastamisel
- tootekategooriate analüüsimisel
- turunduskanalite efektiivsuse hindamisel
- strateegiliste otsuste tegemisel
.

## 🛠 Käsitletud SQL teemad

- GROUP BY
- HAVING
- COUNT(), SUM(), AVG()
- MIN(), MAX()
- CTE (Common Table Expression)
- Window Functions
- ROW_NUMBER()
- RANK()
- LAG()

- Kõige nõrgem kuu oli jaanuar 2024 käibega 85 619 €.

- Uus-segmenti kuulus 1615 klienti.
