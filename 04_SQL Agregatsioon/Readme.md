# 📊 Nädal 4 – SQL Agregatsioon

## 🎯 Eesmärk

Kasutasime SQL agregatsioonifunktsioone ja andmete grupeerimist UrbanStyle andmebaasis, et koostada koondraporteid müügi, klientide, inventuuri ja turunduse kohta.

## 💡 Äriline fookus

Analüüside eesmärk oli toetada UrbanStyle juhtkonda koondnäitajate loomisel, müügitrendide jälgimisel, kliendisegmentide mõistmisel, laoseisu hindamisel ning turunduskanalite efektiivsuse mõõtmisel.

## 🛠 Käsitletud SQL teemad

- GROUP BY
- HAVING
- COUNT(), SUM(), AVG()
- MIN(), MAX()
- CTE (Common Table Expression)
- Window Functions
- ROW_NUMBER()
- RANK()
- LAG()
